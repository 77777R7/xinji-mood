## 开放问题 2：Reddit 原生用户抱怨 —— 已回答（真实原帖 + 链接）

### 为什么放弃情绪追踪（弃用原因分类）

锚点帖：r/bipolar2 "Why I've stopped using mood tracker apps"（42 赞）：

- **监视疲劳 / 自我监控反噬**（原文）："追踪器让我下意识地选择符合图表模式的心情……持续分析自己的情绪让我以不健康的方式脱离了当下。"
- **土拨鼠之日效应**（34 赞）："'哦看我又抑郁了''哦看我又抑郁了'……"——只照镜子不给出路。
- **一天一个心情的模型是坏的**（15 赞）："我一天内可以两头摆（不止一次！），结果图上显示我大部分天都'平均'。"
- **红色太多太致郁**："看到整个月都是负面，我感觉很糟，就彻底不记了。"
- **游戏化惩罚中断**（Finch 用户）：任务越滚越多、断签愧疚感、丧亲后收到"给妈妈打电话"的提示。r/Daylio 有人讽刺："我因为连续麻木好几天拿到了奖励哈哈"（24 赞）。
- **最关键的洞察**：没有人说"追踪没用"——好几个人明确说它**确实**揭示了模式，然后还是退了，因为**洞察到手之后成本没有降下来**。

### 用户在自己动手拼你的产品（最强需求信号）

r/Daylio 一位 2000 天连续记录的用户，每周把 CSV 导给 ChatGPT："分析我的情绪日志，总结我这一周，指出心情和活动之间的模式……最有用的是拿去线下咨询时讨论。"——**这就是心迹的周报，用户在手工造。** 但他附了警告（原文大写）："AI 会从记忆混淆/幻觉里给出虚假数据，把你搞到怀疑人生……它如此自信地对我如此私密的日记给出如此明显的错误信息，非常瘆人。"另有多个同类帖（"用 AI 分析你的 Daylio"）和"每次要花一小时手工整理导出数据"的抱怨——自动化周报的需求是实打实的。

### 对 AI 日记的态度

- **谄媚是第一大抱怨**（2025-04 GPT-4o "glazing" 事件后爆发）：最高赞（97）："它只会告诉你你想听的……ChatGPT 就是个马屁精。其次是隐私。" "好的咨询师会挑战你、推你一把，AI 只会捧着你，输出通用糊糊。"
- **Rosebud 专属差评（r/digitaljournaling）**："AI 反馈越来越不像洞察，更像控制。" "它开始主动给建议，我让它停它不听，这让我火大……我更希望 AI 只在我请求时才给建议。"——**→ 心迹的微行动必须是'轻轻递上'而非'推送灌输'，且要有'不，谢谢'按钮。**
- 隐私多为第二顺位从句（"尤其是免费版"）；**比数据泄露更可怕的信任杀手是 AI 对你自己的日记产生幻觉**——再次确认第一轮的规则：Pattern Card 引用必须来自用户确认过的文本，一字不差。

### 语音日记的真实声音

- 需求集中在**口头处理者、ADHD、悲伤/创伤情境**："我靠说话来处理思绪……可惜说完就忘。语音转文字 + AI 总结回应，太适合这个了。"（r/adhdwomen）"实时字幕的语音日记对我坚持处理情绪有巨大帮助。"
- **黑洞问题（心迹恰好解决的）**，r/digitaljournaling 原文："一开始感觉太棒了，没有结构没有压力，纯粹的原始想法流出来。但后来我意识到……我从来不会回头听。它们像掉进黑洞……让我重听自己叨叨 10 分钟？不可能。"——**语音输入若没有下游的总结/模式产出就是死路。你的 trace 卡片就是那个下游。**
- Daylio 上线语音备忘时用户欢呼"REJOICE"，下一条需求就是"转文字"。

### 每周回顾习惯

- 用户自然收敛到**周为单位**（那位 ChatGPT 用户特意选一周窗口"为了准确性和避免信息过载"）；Daylio 年报有专门的庆祝 Megathread；HN 用户："每周日做一次回顾打分，坚持三年了……把飞驰的念头写下来合上本子，非常平静。"
- 心理科医生的建议被引用："当天晚些时候记录'我的心情**曾是**什么'，而不是'现在是什么'"——**回顾式记录是被偏好的**，对"打卡当下心情"的执念反而制造监视感。

## 开放问题 3：语音日记留存数据 —— 已回答（重要修正）

严谨的预注册对照研究（n=87，6 天交叉设计，Behavior Research Methods 2025）：

- 语音 vs 文字的**打卡次数无显著差异**（3.59 vs 3.23 条，p=.165）——**语音不是留存杠杆**。
- 但**每条信息量是文字的 3.3 倍**（469 vs 142 词，效应量 ηp²=.78），72.3% 用户偏好说话，系统可用性得分 81（前 10%）。
- 独立佐证：Echo Show 研究 73% 偏好语音。
- 被否决的说法：语音生物标记"临床可用"（1-2 否决，只有筛查级精度：敏感度 71.3/特异度 73.5）；"年轻人抗拒语音"（0-3 否决）。
- 2017 调查：文字 EMA 意愿 88.4% vs 语音 80.2% → **语音作为默认、文字作为永远在场的替补**，不是二选一。

**定位修正**：第一轮把语音当作"待验证的楔子"；第二轮结论是——**语音的价值是信号密度：3.3 倍的语料 → 更准的 Pattern Card → 闭环成立 → 闭环才是留存机制**。宣传语应该是"30 秒说清楚，比打字多 3 倍线索"，而不是"语音让你更容易坚持"。

## 开放问题 4：周报推送时机 —— 框架层面已回答（无直接 A/B）

- 实证（N=189，6 周）：健康干预通知的响应高峰在 **10:00-18:00**，最低谷是**周末早晨**；接收度是瞬态的（一天内变化），不接收时段的推送无益且加剧疲劳；ML 用情境特征预测接收度可比基线好 77%。
- **接收度与结果相关 r=0.53**：高响应日的目标完成率高 62% —— 推送时机不只是增长技巧，**可能直接影响干预效果**。这给"模式触发式提醒"加了一层含义：它是效果驱动器，是竞品发固定提醒时你能讲的差异化故事。
- JITAI 经典框架（Nahum-Shani 2018）：最优时机是**事件触发**（脆弱窗口+机会窗口+接收状态），不是钟表时间。
- **没有找到"周日晚最优"的直接证据**（诚实标注）。设计修正：周报**周日晚生成完毕**（迎合用户自发的周日回顾仪式），但**推送通知避开周末早晨、落在工作日白天接收度窗口**（如周一 10 点后），并允许用户自定义。Whoop 用周一早的先例与此一致。

## 与第一轮优化方案的对照：确认 / 修正 / 新增

### 被加强确认的

1. **闭环是唯一护城河** ✅✅ —— Reflectly 坍塌（1000 万用户→月收 <$5K→卖身）+ 心岛日记停更转型 + Reddit 用户手工用 ChatGPT 拼周报 + 学术研究（32 款 app 仅 7 款支持行动阶段）四重印证。
2. **证据引用必须来自用户确认文本** ✅ —— Reddit 用户对"AI 对我日记产生幻觉"的恐惧比隐私更强烈。
3. **不做 streak、不惩罚中断的品牌规则** ✅ —— Finch 的断签愧疚、Daylio 的"麻木奖励"都是反面教材，你 docs 里已有这条规则，现在有据可依。
4. **模式触发式提醒蓝海** ✅ —— 加码：接收度→效果 r=0.53，它还是效果驱动器。

### 需要修正的

5. **语音定位**：从"留存楔子"改为"信号密度优势"。营销与产品叙事都要改：卖点是"更准的模式识别"，不是"更容易坚持"。文字替补永远在场。
6. **周报推送时机**：第一轮建议"默认周日晚推送"；修正为"周日晚生成、避开周末早晨推送、默认工作日白天通知、用户可改"。
7. **留存目标从'打败品类 3%'改为具体对标**：D7 ≥40%（Rosebud 发布队列）、D30 奔 35%+（Daylio 实测 37.7%）。低摩擦记录（Daylio 模式）+ 有产出的洞察，两者你都要。

### 全新增加的（第一轮没有的发现）

8. **反监视设计（本轮最大的新原则）**：Reddit 最高赞弃用原因不是"没用"，是"被监视感/过度自我监控让我脱离当下"。设计对策：
   - 支持**回顾式记录**（"昨天和前天感觉如何"），不逼用户实时打卡当下情绪；
   - 一天多次 check-in 合法化（一天一心情的模型被用户明确唾弃），你的 trace 模型天然支持，把它做成显性卖点；
   - **"毕业"概念**：循环消退后主动建议降频（"这个循环 3 周没出现了，要不要改成每周两次轻打卡？"）。用户把"不再需要追踪"体验为康复——顺着这个走，别对抗它。这可能是全品类没有人敢做的留存哲学：**帮用户减少使用**，反而赢得信任与口碑。
9. **行动必须是"递上"而非"推送"**：Rosebud 被骂就骂在"不请自来的建议、让它停它不停"。你的行动推荐默认收起（"有一个可以试的小实验，想看吗？"），并保留"今天不要"且不追问。
10. **杠铃战略**：习惯机制学 Finch（宠物/仪式感的温度，但不必养鸟），AI 深度学 Rosebud（但用本地规则引擎避开它的记忆失效），中间用行动闭环焊死——这个组合位没有人占。
11. **中文市场再校准**：真正的体量对手是 Moo日记（14 万评分，树洞+社区路线），心光是质量对手（AI 陪伴路线）；两者都没做"模式→行动→验证"。心岛日记之死再次警告：纯记录 + 情绪标签 = 死路。

### 仍未解决（诚实清单）

- 心光的下载/收入第三方数据（七麦/点点全部登录墙）；
- 2025-2026 新入场者（Dot、Ash by Slingshot、Manifest、Apple Journal API 采用度）的核验级情报——工作流该角未产出任何过验证的结论；
- 语音日记 30/90 天留存（唯一严谨研究只有 6 天、本科生样本）；
- 周报时机的直接 A/B——只能靠你自己上线后测。

## 更新后的行动优先级（合并两轮）

1. **Pattern 反馈按钮 + 循环生命周期 + "毕业"降频机制**（原 P1 + 新反监视原则）
2. **行动效果回访 + 归因展示，行动推荐改为"递上"式交互**（原 P2 + Rosebud 差评教训）
3. **周报：章节叙事 + ≥3 次打卡解锁 + 周日晚生成/工作日白天推送 + 回顾式补记入口**（原 P3 + 时机证据 + 回顾式偏好）
4. **App.tsx 拆分 + draft 状态机 + 服务端可部署化**（不变）
5. **me tab 隐私面板**（不变；Reddit 证据：隐私是次要从句但幻觉是主要恐惧 → 面板里加"AI 引用核对"说明，展示"所有引用均来自你确认过的文字"）
