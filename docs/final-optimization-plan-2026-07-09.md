# 心迹 Mood 最终优化方案（2026-07-09）

> 基于两轮深度研究（200+ agent、44 条经 3 票对抗核验的结论、Reddit 原帖挖掘、竞品硬数据、本项目代码库完整分析）收敛而成的执行蓝图。研究依据见 `deep-research-report-2026-07-09.md` 与 `deep-research-round2-2026-07-09.md`。

---

## 0. 一页纸总纲

**定位一句话**：心迹是唯一跑通「模式洞察 → 微行动 → 验证有效 → 反哺」闭环的情绪产品——别人告诉你"你这周很焦虑"，心迹告诉你"周日晚焦虑→浅睡→周一易怒这个循环第 4 次出现了，上次 10 分钟散步对你有效，今晚再试一次？"

**杠铃定位**：Finch 级习惯温度（~$30M ARR 证明规模存在）+ Rosebud 级 AI 深度（D7 40% 证明粘性存在）+ 两者都没有的行动闭环焊在中间。

**北极星指标**：不是打卡次数，是**"闭环时刻"次数**——用户看到"你做了 X 之后，循环 Y 没有再出现"的次数。

**留存目标线**：D7 ≥ 40%（Rosebud 发布队列水平）、D30 ≥ 30%（Daylio 实测 37.7% 为天花板参照）。品类均值 3% 是死亡线不是目标。

**四条铁律**（全部有研究背书，写进每一次产品决策）：
1. **反监视**：永不制造"被盯着"的感觉——不做 streak、支持补记、循环消退后主动建议降频（"毕业"）。
2. **递上不推送**：所有 AI 建议默认收起，用户点开才展开；"今天不要"永远可选且不追问。
3. **证据可核查**：AI 的每一句引用都来自用户确认过的文字，一字不差；置信度说人话；主动承认不确定。
4. **语音是信号密度不是留存钩子**：卖点是"30 秒说清楚 = 3 倍线索 = 更准的模式"，文字入口永远在场。

## 1. 六周执行计划

### 第 1-2 周：把闭环焊上（P0，全部是产品性命）

**1a. Pattern 反馈按钮**（规格书 mvp-data-contract.md:287-338 已设计，直接实现）
- Loop 达到"可见"（≥3 次）时，卡片下方两个按钮：「是这样的」/「不太对」。
- 「是这样的」→ confidence 加权、进入"已确认模式"列表、解锁行动入口。
- 「不太对」→ 降权 + 一个单选追问（场景不对/感受不对/没有这回事）反哺 loopCandidateKey 归一化。
- 数据落点：新增 `UserPatternFeedback` 实体，进 `dataFoundation` 的 loop 计算。

**1b. 行动效果回访（闭环时刻）**
- 行动完成后的下一次 check-in 结束时检查：同一 chainKey 的 loop 是否复现。
- 未复现 → 展示归因卡："上次「10 分钟散步」之后，这个循环这周没有再出现。"（措辞永远"可能有帮助"；同一行动累计 3 次正反馈才升级为"对你通常有效"。）
- 复现 → 不指责，温和展示："它又来了。要不要换一个更轻的？"（走已有的 too_much_lighter 路径。）
- 补上规格书里缺失的 `did_not_help` 主动降权（action-system-v1.md:503）。

**1c. 行动交互改为"递上"式**
- 推荐默认收起为一句话："有一个可以试的小实验，想看吗？"
- 「今天不要」一键关闭，不追问、不重复推送。

### 第 3-4 周：周报重构 + 循环生命周期（P1，留存引擎）

**2a. 周报改为章节化叙事**（5-7 张可滑动卡片，替换现有单屏）
1. 这周的天气（总体基调，意象化）
2. 出现的循环（哪个来了几次，附证据原文片段）
3. 你做了什么（行动 + 效果归因）
4. 变化（只和自己的前 3 周基线比，永不与他人比）
5. 人物志（本周记录中出现的人——Rosebud 被验证的惊喜点）
6. 下周的一个 if-then
7. 一张可分享卡（只有意象和基调，零敏感内容）
- **门槛机制**：≥3 次 check-in 解锁完整版；1-2 次给"轻量版"（把那一两次写好，绝不显示空表格）。
- **时机**：周日晚生成（迎合自发的周日回顾仪式）；推送通知落在工作日白天接收度窗口（默认周一 10:00 后），避开周末早晨；用户可改。
- **修口径 bug**：改自然周（明确周起始日），与 Patterns tab 统一，替换现有滚动 7 天窗口。

**2b. 循环生命周期（含"毕业"机制）**
- 已确认 loop 三态：活跃（近 5 天出现）→ 沉睡（14 天未现，周报庆祝"两周没来了"）→ 复发（温和提示 + 上次有效行动）。
- **毕业降频**：某 loop 沉睡 ≥3 周 → 主动建议："要不要改成每周两次轻打卡？" 循环消退是产品成功指标，让用户看见并顺着"不再需要追踪 = 康复"的体验走。
- 证据链露出：点开卡片可见"基于这 N 条记录"（similarPastCheckInIds），每条附用户确认过的原话。

**2c. 补记入口（反监视）**
- Today 页加"补记昨天/前天"轻入口（文字即可），响应"记录曾是什么而非现在是什么"的用户偏好；一天多次 check-in 在 UI 上显性合法化。

### 第 5-6 周：工程还债 + 信任面（P2，规模化前提）

**3a. App.tsx 拆分**：按缝拆——4 个 screen 组件 + 规格书的 `DRAFT_TRANSITIONS` reducer（useReducer + context，不引重型状态库）；给状态机补契约测试（并入 contract_tests.mjs）。

**3b. 服务端可部署化**：客户端 API 地址环境变量化（删掉三处硬编码 localhost:8084）；bearer token 鉴权；每用户每日调用配额 + 简单限流；模型名改为真实存在的模型；两份安全关键词表（server:269 / dataFoundation.ts:503）抽成共享 JSON。

**3c. me tab 从死按钮变隐私面板**：导出 JSON、一键删除、本地模式开关、以及一条信任声明："所有 AI 引用均来自你确认过的文字。"（Reddit 证据：比数据泄露更可怕的是 AI 幻觉引用。）

### 六周后再决定：native 化
- 近期承认是 web app，用 PWA 分发验证闭环与留存（你缺的是留存数据，不是应用商店）。
- D30 数据证明闭环成立后，再做 expo-av + AsyncStorage/SQLite 的 native 里程碑。

## 2. AI 框架终版设计

**总原则：本地规则做纵向、LLM 做单次提取和措辞——保持现有架构，定向增强。**（Rosebud 的记忆失效差评证明纯 LLM 纵向记忆不可靠；你的本地 loop 引擎是护城河，不是权宜之计。）

1. **`/reflect` 加薄记忆**：请求中附结构化摘要（活跃 loop 候选 key/次数/置信度 + 最近 3 条 chainKey + 行动帮助度摘要），让即时回应能说"这和你周二说的像"。成本 +几百 token。
2. **防谄媚 system prompt**：先具体后共情；引用原话作为证据；不做无据断言；有证据的温暖而非无条件肯定。（Reddit 第一大 AI 抱怨是 sycophancy。）
3. **置信度人话化**："过去 5 天出现 3 次，都在晚上" 替代任何数字分数；卡片主动写一句替代解释（"也可能只是这几天都没睡好"）。
4. **引用铁律**：Pattern Card 引用只来自用户确认过的转写文本。转写后一键修正保留。
5. **不做声纹情绪检测**：研究核验只有筛查级精度（敏感度 71.3），拿它当卖点会翻车。语音价值 = 3.3 倍语料密度，到此为止。

## 3. Action 库终版设计

- **规模**：第一阶段 12-18 个（现有 6 个扩展），每个 loop 类型（身体紧张/思维反刍/情绪低落/睡眠）× 3-4 个负担等级。不超过 20——Bearable 的选项过载教训。
- **格式**：全部 if-then（实施意图，d≈0.99 的最强证据形式）——"如果明天下午胸口又发紧，就离开工位走 5 分钟"。Pattern Card 提供 if，action 提供 then，这个接口竞品做不到。
- **科学骨架**：行为激活对抑郁类 loop（短中期有效）；焦虑类 loop 主打身体调节（呼吸/着地，BA 对焦虑无显著效应）。
- **持续再触发**：BA 效应 12 个月消退 → 靠模式触发式提醒维持，不指望一次干预。
- **模式触发式提醒（蓝海）**：检测到"周日晚循环" → 周日 18:00 发具体到模式的提醒。研究显示仅 7% 的干预测过情境触发，且接收度与效果相关 r=0.53——这是可宣称的效果差异化。

## 4. 上线后必须自己测的（研究给不了的答案）

1. 周报推送时间 A/B（周一白天 vs 周日晚）——无公开证据，你来补。
2. 语音 vs 文字用户的 D30 差异——学界只有 6 天数据。
3. "毕业"降频对留存的净效应——全品类无人做过，你是第一个数据点。
4. 付费墙位置：研究建议锁"深度周报 + 无限行动库 + 长期模式档案"，免费层保留完整 check-in + 基础卡片（Rosebud 付费墙太狠是差评源，心光试用太短同样被骂——给足 7-14 天体验闭环再收费）。

## 5. 明确不做清单

- ❌ 全历史塞 LLM 的"深度记忆"（Rosebud 差评已证伪）
- ❌ streak / 打卡排行 / 用户间比较（弃用研究 + 品牌规则）
- ❌ 声纹情绪识别卖点（只有筛查级）
- ❌ 60+ 行动库（选项过载）
- ❌ 社区/树洞功能（Moo日记的路线，与你的闭环定位稀释）
- ❌ 每天固定时间的通用推送（54% 竞品在做的低效方案，你做模式触发）
